## 3. System topology (3 layers, verbatim Polsia)

```
Layer A — Agency HQ (our Express monolith on Render)
  Routes:   /api/* (REST + SSE) · /ai/openai/v1/* · /api/proxy/{ai,email,r2}/*
  Cron:     6h cycles · 06:00 review · 03:00 memory curation · 30min broadcast
  Agents:   claude-agent-sdk runtime · 25 MCP servers as stdio children
  Stores:   Neon PG (~80 tables) · Upstash Redis (rate limit) · R2 (files)

Layer B — Per-client studio (auto-provisioned per customer)
  Forked from _engine-starter-template (we capture Polsia's verbatim)
  All AI calls route back to Layer A's /api/proxy/ai (POLSIA_API_KEY env)
  Customer's portfolio site code, Neon namespace, Postmark sender, Stripe Connect

Layer C — Per-task workspace (sandbox)
  /tmp/dearme-workspaces/{brand}/{agent}/{exec}/
  git clone --depth=1 customer repo · spawn claude-code subprocess
  Mounted MCP via stdio per agent_tools row
  Cleanup after success / 24h orphan GC
```

## 6. The voice gate (the only DearMe-original moat)

```
Every outbound (tweet / cold email / site copy / chat-as-user) →

  voice_profile.score_post({ post_text, voice_profile_id })
    → { score, signature_matches, forbidden_hits, pass }

  pass=true (≥0.7)  → send via channel + log to voice_match_history
  pass=false        → re-prompt agent with feedback (max 3 retries)
                    → if still fail → escalate to chat for human approve
```

Mounted on agents: Twitter, Opportunity Hunter, Chat, Onboarding, Support.
**This is the only NEW MCP server vs Polsia.**

## 7. Side Hustle Mode (only the auto-config delta)

When `brands.work_mode = 'side_hustle'`, the system flips defaults:

```
cycle_frequency       6h   →  12h
autonomy              autonomous → supervised
approval queue        single   →  batch (review at lunch / EOD)
posting windows       any  →  Mon-Fri 8am/12pm/5pm + Sat 10am
daily letter length   200w →  100w
meta_ads              on   →  off (don't burn side-rev)
inbox_triage          auto-reply →  draft-only
```

**One toggle in settings. Zero feature divergence — same product, kinder defaults.**
