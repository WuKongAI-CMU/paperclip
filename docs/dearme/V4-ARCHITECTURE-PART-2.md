## 10. AI proxy (verbatim Polsia mechanics + voice gate)

```
Customer's Render service (Layer B):
  ENV: POLSIA_API_KEY=<32-byte> · OPENAI_BASE_URL=https://dearme.app/ai/openai/v1
       POLSIA_API_URL=https://dearme.app/api/proxy/ai

Customer code (verbatim Polsia bencera/lib/polsia-ai.js):
  openai.chat.completions.create({ model, messages, task: 'cust-X-Y' })
  anthropic.messages.create({ model, ... }, { headers: { 'X-Subscription-ID': ... } })

Layer A proxy (we wrote this Day 2, ✅ done):
  1. Auth: Bearer key → brand_id
  2. ⭐ Voice gate (if outbound content): score ≥ 0.7
  3. Budget gate: brand.monthly_budget_usd not exceeded
  4. Forward to Sapiom OR Anthropic OR OpenAI (model picker)
  5. Log to executions: brand_id, model, tokens, cost_usd, task metadata
  6. Return verbatim
```

**Already implemented in `routes/proxy-openai.js` and `routes/proxy-ai.js`** (Day 2). Voice gate is the only piece pending — added when MCP voice_profile ships.

## 11. Cycle engine (verbatim Polsia 3-phase)

```
Every 6h (12h for Side Hustler) per active brand:

Phase 1 — Plan (~5 min)
  Manager (id 51) builds context from brand_documents + memory L1/L2/L3 +
  recent reports + open tasks. LLM with planning prompt → 3-8 task JSON.
  INSERT cycles + INSERT tasks. SSE: type=cycle_started.

Phase 2 — Execute (4-6h, sequential per agent type, parallel cross-agent)
  task-worker.js polls every 30s WHERE status='todo' ORDER BY priority + queue_position.
  For each task:
    - Lock: status='in_progress', started_at=NOW()
    - Spawn /tmp/dearme-workspaces/{brand}/{agent}/{exec}/
    - git clone customer repo
    - claude-agent-sdk subprocess + mounted MCP servers
    - Stream thinking → SSE bus → customer browser
    - On finish: status='completed', cost_usd ledger, score=NULL
    - Cleanup workspace

Phase 3 — Review (~5 min, +6h or when all tasks done)
  Reporting (id 35) aggregates: accomplished, failed, blocked.
  LLM summarize → cycles.review_summary.
  Build "Dear me, day N" letter ≤200w (≤100w side hustle).
  Send via Postmark + post to chat. SSE: type=cycle_completed.
  cycles_completed++.
```

**Self-scheduling:** after Phase 3, setTimeout(intervalMs) reschedules next cycle. Cron at 03:00 catches orphans.
